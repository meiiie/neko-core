02Approvals

It asks before it touches your machine.

Neko puts the tools that only look in one category and the tools that change something in another. The first category runs straight away. The second waits for you, and the line between them is printed by a command you can run yourself.

Read now, write on approvalread_file, search, glob and ls run immediately. write_file, edit and bash wait for you to say yes.
Autonomy has a nameTurning approvals off is a mode you enter deliberately, and the session footer shows it for as long as it is on.
Checkable, not promisedneko policy re-derives the boundary from the source and exits non-zero when anything has drifted.

03Models

Adding a model means editing one file.

Neko speaks to any OpenAI-compatible endpoint — a hosted API, your work account, or a model server running on the machine in front of you. The last one is what makes it work with the network unplugged.

A LOCAL PROFILE~/.neko-core/config.json
{
  "active_profile": "local",
  "profiles": {
    "local": {
      "base_url": "http://127.0.0.1:8080/v1",
      "auth": "none"
    }
  }
}
Subscriptions or API keysChatGPT, Claude, Gemini, Grok, Kimi and DeepSeek sign in from inside the app. Anything else is a base URL away.
Or nothing at allPoint a profile at llama.cpp or Ollama and every byte stays on your hardware.
Switch mid-task/provider and /model change the endpoint while a session is running. The conversation carries over.

04Oracle

A second opinion from a model that cannot touch your machine.

When Neko is stuck it can send a chosen slice of your project to a stronger model and ask what it thinks. That model is handed no tools at all: it cannot open a file on your disk, run a command, or change a line. It receives exactly the files you approved and sends back text.

You see the manifest firstEvery file in the bundle is listed before the request goes out, and --dry-run stops there.
Credential stores are dropped whole.env, private keys and anything under .neko-core/ never enter a bundle.
Your code arrives readableOnly key-shaped string values are masked, so process.env.API_KEY reaches the oracle exactly as you wrote it.
DRY RUNNOTHING SENT
$ neko oracle --dry-run \
    -p "why does the transcript stall?" \
    -f "src/adapters/meeting-*.ts"

Bundle: 6 file(s), 92 KB, about 23k tokens.

  + src/adapters/meeting-vad.ts (7 KB, 1 masked)

05Extending

One Markdown file teaches it a new job.

Coding is what Neko does out of the box, and a skill is how it learns anything else. Write the instructions once in a folder; Neko loads them only when a task actually matches, so a wide library costs nothing to carry.

A SKILLskills/procurement/SKILL.md
---
name: procurement
description: sourcing, quotes, supplier checks
---

# When to use this
A request to buy, price, or compare suppliers.

# Rules
- A human approves every purchase.
- Quote in VND and name the source of each price.
SkillsDescribe how you want a job done once, and Neko finds it the next time that job comes up.
MCPAny MCP server plugs in, and a project that already has .mcp.json works untouched.
MemoryDecisions survive between sessions as plain files you can open, edit or delete.

07Install

Two ways to install, both about a minute.

Neko ships as a single standalone file. Node, Bun, Python and an account are all things you can skip.

RECOMMENDED

Paste one line

The installer picks the right build for your machine, puts neko on your PATH so any terminal can find it, and keeps it updated afterwards.

> irm https://neko.holilihu.online/install.ps1 | iex
$ curl -fsSL https://neko.holilihu.online/install.sh | sh

Never used a terminal? Press Start, type PowerShell, open it, paste the line above, and press Enter. When it finishes, type neko and press Enter again.

Or take the file

The same program as a plain download, for when you would rather place a file yourself than run a command.
