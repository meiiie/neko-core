Product: Neko Core

Neko Core is a local-first terminal coding agent, shipped as one standalone binary for Windows, macOS and Linux.

  1. Governed loop

    Routine edits proceed. Risky actions — credentials, destructive shell commands, and policy changes — are gated and auditable. Credential targets and catastrophic shell commands remain hard refusals.

  2. MCP, skills, ACP, sessions

    Neko Core supports MCP and skills, editor integration via ACP (Agent Client Protocol) for Zed, JetBrains and other clients, and durable sessions that can resume after an interrupt without silently replaying mutations.

  3. Oracle

    Oracle mode asks a second model for an opinion. That model is given no tools: it cannot open a file, run a command, or edit the machine. It sees only the files approved for that request.

  4. Claude

    Claude is a first-class provider. Neko Core also works with other configured providers; models and endpoints are configuration, not separate products.
