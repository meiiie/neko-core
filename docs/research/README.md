# Research archive

These are dated design inputs, incident investigations, and source reviews. They are retained as evidence, not
as current product contracts. File dates are part of their identity; later code, tests, and process documents
may supersede their conclusions.

For current behavior start at [../README.md](../README.md), especially the harness architecture, testing
contract, and capability guides. New research should state its date, sources, verified gap, and the exact Neko
component it may influence. An idea remains non-normative until implemented and tested.
